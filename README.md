# Phornphat Personal Portfolio

เว็บ Personal Portfolio ของผม สร้างขึ้นมาเพื่อรวบรวมผลงาน โปรเจกต์ที่เคยทำ ทักษะต่างๆ รวมถึงเกียรติบัตรที่เคยได้รับ เน้นงานดีไซน์สไตล์ Dark Mode โทนสีดำตัดส้ม คลีนๆ และรองรับการใช้งานทุกหน้าจอ

Live Demo: https://phornphat.vercel.app

---------------------------------------------------

## Tech Stack

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Deployment: Vercel
- Icons & Assets: Lucide Icons / Custom SVG


---------------------------------------------------

## Features

- Dark Mode First: ดีไซน์โทนสีดำ-ส้ม
- Multi-language Support: รองรับการเปลี่ยนภาษา TH / EN
- Responsive Design: แสดงผลได้ทั้งบนมือถือ แท็บเล็ต และจอคอม
- Project Showcase: แสดงผลงานการพัฒนาเกม พัฒนาเว็บ และงาน UX/UI
- Certificates Gallery: แกลเลอรีแสดงผลงานและเกียรติบัตรพร้อมระบบพรีวิวรูปภาพ


---------------------------------------------------
